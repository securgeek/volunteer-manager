## Theme files

"Theme Files" means files that only change how the volunteer portal or the organizer app
looks, and nothing about what they do:

1. stylesheets (CSS), such as `frontend/src/assets/portal-theme.css`;
2. images, logos, icons and fonts, such as those in `frontend/public/` and `maintenance/`;
3. the maintenance page's markup and styles (`maintenance/index.html`).

A file is a Theme File only if it contains no executable code: no JavaScript, Python, shell or
other program logic, and no template, style or markup that changes what the software
collects, stores, sends or allows.
